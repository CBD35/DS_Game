# Playthrough Notes — Dark Sun: Shattered Lands (1993)

This directory is where the project owner documents their direct experience playing the original SSI game.

**These notes are the ground truth for the remake.** When any GDD content conflicts with what is actually in the original game, the original game wins — and that means these notes win.

## How to Use This Directory

Play the original game (DOSBox or GOG). As you play, fill in these files:

| File | What to Document |
|---|---|
| `01_chapter_notes/` | Notes per location/chapter as you go |
| `02_characters.md` | Every named NPC — description, role, what they say, what they give |
| `03_locations.md` | Every area — layout, what's there, what matters |
| `04_quests_and_story.md` | Every quest — how it starts, steps, outcomes, flags |
| `05_items_and_equipment.md` | Every named item — stats, where found, what it does |
| `06_unfinished_and_cut.md` | Things that felt abruptly cut, unresolved, or hinted but not followed through |

## Recording the Game

- **OBS Studio** (recommended): Window capture of DOSBox, records video + audio
- **DOSBox built-in**: `Ctrl + Alt + F5` toggles video capture to `.avi` in the `capture/` folder

## What to Note

For each location, try to capture:
- [ ] Map layout (rough sketch or description)
- [ ] All named NPCs and what they say
- [ ] All items found and where
- [ ] Quest triggers and outcomes
- [ ] Any dialogue that felt significant
- [ ] Anything that felt unfinished, abrupt, or like it was cut short
- [ ] Atmosphere — how it looks, sounds, what the tone is

## Source Documents

The official manual and cluebook are in Google Drive at `Game Design/DS/`:
- `ds_shatterland_manual_pdf.pdf` — Rules, classes, spells, races, bestiary
- `ds_shatterland_cluebook_pdf.PDF` — Full walkthrough with every NPC, item, and map

Cross-reference your notes against these when unsure.
