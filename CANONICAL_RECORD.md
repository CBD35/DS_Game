# Canonical Record — Dark Sun: Shattered Lands (1993)

This file records facts **confirmed directly from the original game or its official source documents** (manual + cluebook). It is the single source of truth for all GDD and remake decisions.

When any GDD file conflicts with this record, **this record wins**.

Source documents: `ds_shatterland_manual_pdf.pdf` and `ds_shatterland_cluebook_pdf.PDF` (Google Drive: `Game Design/DS/`)

---

## Confirmed: Core Setting

| Fact | Source |
|---|---|
| Game is set in city-state of **Draj** | Manual p.1 |
| Sorcerer-King is **Tectuktitlay** | Manual p.1 |
| Party begins as gladiatorial slaves in the **Arena of Draj** | Manual / Cluebook |
| The world is **Athas** | AD&D 2e Dark Sun setting |
| The sun burns **red** (crimson) | Manual |
| Metal is **extremely rare** — bone, obsidian, chitin, stone are standard | Manual |
| No divine gods — **elemental clerics** only | AD&D 2e Dark Sun |
| All characters begin as **1st-level psionicists** | Manual |

|---|---|---|

| HP floor | 0 HP = unconscious; −10 HP = dead | Manual |
